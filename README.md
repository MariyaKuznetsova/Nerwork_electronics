# Проект онлайн платформы-торговой сети электроники

## Описание:

Проект онлайн платформы-торговой сети электроники

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:MariyaKuznetsova/Nerwork_electronics.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. В платформе-торговой сети, вы можете создать звенья сети (контакты, продукты, поставщик, задолженность).
2. В платформе-торговой сети, вы можете посмотреть, удалить, редактировать звенья сети, только если вы активный авторизованный пользователь.
3. Также вы можете очистить задолженность перед поставщиком.
4. В админ-панели вы можете отфильтровать по городу звенья сети, посмотреть их уровень.
